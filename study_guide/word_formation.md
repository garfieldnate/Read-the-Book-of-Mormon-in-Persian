## The abstract-noun suffix ـی / ـگی (*-ī* / *-gī*)

Persian has a **fully productive** suffix **-ī** (ـی) that converts adjectives, agent nouns, and compound descriptors into abstract nouns meaning "the quality, state, or practice of X." It is one of the most common derivational patterns in the language, and the source of a large number of the nouns you will encounter in this text. Whenever you see a noun ending in ـی that can be decomposed as `[adjective or agent noun] + ی`, this pattern is almost certainly at work — even for words you have never seen before.

### From adjectives

| Base | | + ـی | |
|------|-|------|--|
| `خوب` *xūb* "good" | adj | `خوبی` *xūbī* | "goodness" |
| `آگاه` *āgāh* "aware, informed" | adj | `آگاهی` *āgāhī* | "awareness, knowledge" |
| `نیک` *nīk* "good, virtuous" | adj | `نیکی` *nīkī* | "virtue, goodness" |
| `دارا` *dārā* "having, wealthy" | adj | `دارایی` *dārāyī* | "possessions, wealth" |
| `خیره سر` *xīre-sar* "stubborn" | compound adj | `خیره سری` *xīre-sarī* | "stubbornness" |
| `سخت دل` *saxt-del* "hard-hearted" | compound adj | `سخت دلی` *saxt-delī* | "hard-heartedness" |

### From agent nouns

Agent nouns — words ending in ـار *-ār*, ـگر *-gar*, ـدار *-dār*, ـگزار *-gozār*, etc. that denote "one who does/has X" — take -ī to mean "the practice or condition of being that kind of person":

| Base | | + ـی | |
|------|-|------|--|
| `نگهدار` *negah-dār* "guardian, keeper" | agent noun | `نگهداری` *negah-dārī* | "keeping, preservation, maintenance" |
| `پرهیزکار` *parhīzkār* "pious, abstinent" | agent noun | `پرهیزکاری` *parhīzkārī* | "piety, righteousness" |
| `سپاسگزار` *sepāsgozār* "grateful" | agent noun | `سپاسگزاری` *sepāsgozārī* | "gratitude, thanksgiving" |
| `فرمانروا` *farmān-ravā* "ruler" | agent noun | `فرمانروایی` *farmān-ravāyī* | "rule, sovereignty" |
| `رؤیانگر` *roʾyānegar* "visionary" | agent noun | `رؤیانگری` *roʾyānegerī* | "the state of being a visionary" |

### The ـگی allomorph after silent ـه

When the base ends in a **silent ه** (pronounced *-e* but written ه), the suffix takes the form **-gī** (ـگی) — the *g* is a linking consonant that prevents two vowels from colliding:

| Base | | + ـگی | |
|------|-|-------|--|
| `زنده` *zende* "alive" | adj | `زندگی` *zendegī* | "life" |
| `ساده` *sāde* "simple, plain" | adj | `سادگی` *sādegī* | "simplicity" |
| `شرمنده` *šarmande* "ashamed" | adj | `شرمندگی` *šarmandegī* | "shame, embarrassment" |
| `آکنده` *ākande* "filled" | adj | `آکندگی` *ākandegī* | "fullness" |

### Three uses of ـی — don't confuse them

The letter ی produces three completely different grammatical effects depending on what it attaches to and where it sits in the sentence:

| Use | What it attaches to | Result | Example |
|-----|---------------------|--------|---------|
| **Abstract noun** (this section) | adjective or agent noun | a new noun | `خوب` → `خوبی` "goodness" |
| **Indefinite marker** | any noun | "a, some, a certain" | `مرد` → `مردی` "a man" |
| **Relativizer** | noun before a `که` clause | identifies the antecedent | `خدایی که` "the God who…" |

The abstract-noun use is recognizable because the result is itself a noun that stands alone (it is not followed by که, and it does not mean "a [noun]"). When in doubt, ask: does the ـی-word name a quality, state, or practice? If so, it is the abstract suffix.

## The adverb/adjective suffix ـانه (*-āne*)

Persian has a **fully productive** suffix **-āne** (ـانه) that attaches to nouns and adjectives to create words meaning "in the manner of X" or "befitting X." The resulting form can function as either an **adjective** (modifying a noun before it) or an **adverb** (modifying a verb after it) — context determines which reading applies.

| Base | | + ـانه | |
|------|-|--------|--|
| `خرد` *xerad* "wisdom, reason" | noun | `خردانه` *xerad-āne* | "wisely, wise" |
| `مرد` *mard* "man" | noun | `مردانه` *mard-āne* | "manly, courageously" |
| `دوست` *dust* "friend" | noun | `دوستانه` *dust-āne* | "friendly, in a friendly manner" |
| `دشمن` *došman* "enemy" | noun | `دشمنانه` *došman-āne* | "hostile, in a hostile manner" |
| `سال` *sāl* "year" | noun | `سالانه` *sāl-āne* | "annual, annually" |
| `عاقل` *ʿāqel* "wise, rational" | adj | `عاقلانه` *ʿāqel-āne* | "sensibly, prudently" |
| `جاهل` *jāhel* "ignorant" | adj | `جاهلانه` *jāhel-āne* | "ignorantly, foolishly" |

### With بی‌ compounds

The suffix attaches freely to **بی‌-** ("without") compounds, producing adverbs that mean "in the manner of one who lacks X":

| Base | | + ـانه | |
|------|-|--------|--|
| `بی خرد` *bī-xerad* "lacking wisdom, senseless" | بی‌ compound | `بی خردانه` *bī-xerad-āne* | "foolishly, senselessly" |
| `بی رحم` *bī-rahm* "merciless" | بی‌ compound | `بی رحمانه` *bī-rahm-āne* | "mercilessly" |
| `بی عدالت` *bī-ʿadālat* "unjust" | بی‌ compound | `بی عدالتانه` *bī-ʿadālat-āne* | "unjustly" |

### The ـگانه allomorph after silent ـه

Parallel to the -ī/-gī pattern, when the base ends in a silent ه (pronounced *-e*), the suffix takes the form **-gāne** (ـگانه):

| Base | | + ـگانه | |
|------|-|---------|--|
| `بچه` *bačče* "child" | noun | `بچگانه` *bačče-gāne* | "childish, childishly" |
| `دسته` *daste* "group" | noun | `دستگانه` *dast-gāne* | "collectively" |

### Function: adjective and adverb simultaneously

Unlike English, where "friendly" (adj) and "in a friendly manner" (adv) are distinct forms, a single ـانه word covers both roles. Word order and context tell you which is meant:

| Persian | Reading | Meaning |
|---------|---------|---------|
| `رفتار دوستانه` *raftār-e dust-āne* | adjective | "a friendly manner" (modifies رفتار) |
| `دوستانه رفتار کرد` *dust-āne raftār kard* | adverb | "he behaved in a friendly way" (modifies رفتار کرد) |
